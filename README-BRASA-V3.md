# Brasa Marketplace v3

Esta iteración amplía Brasa desde marketplace de parrilleros a marketplace de servicios para eventos.

## Flujo funcional disponible
- Explorar categorías y prestadores.
- Filtrar por categoría, comuna, verificación y orden.
- Abrir perfil del prestador y agregar uno o más servicios.
- Servicios por persona recalculan su costo según cantidad de invitados.
- El evento y sus servicios persisten en localStorage.
- Control de presupuesto en `Mi evento`.
- Checkout demostrativo con fecha, ubicación y datos de contacto.
- Creación de solicitud/reserva local con código BR-XXXXXXXX.
- Página `Mis reservas` para revisar solicitudes creadas.
- Comparador demostrativo de precios que considera precio + despacho.
- Planificador de evento existente y recomendación de prestadores.
